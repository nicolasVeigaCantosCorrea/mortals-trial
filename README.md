# ⚔️ Mortal's Trial

A small 2D survival arena game built with Godot and GDScript, featuring handmade pixel art.

This project was created to learn practical game development by building and finishing a (small)playable game.
To win one has to survive for 60s.

## 🕹️ Gameplay

Survive a small arena filled with enemies!

- Move your character using WASD or arrow keys.
- Automatically attack nearby enemies.
- Survive until the timer runs out.
- Defeat enemies, avoid damage, and try again!

## 🛠️ Built With

- **Godot** — Game engine
- **GDScript** — Gameplay programming
- **Aseprite** — Handmade pixel art and animations
- **GitHub Actions** — Automated game exports

## 📚 What I Learned

This project explores Godot scenes, signals, reusable resources, physics and collisions, character animation, particle effects, tile-based level design, and exporting standalone games.
